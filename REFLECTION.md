# Reflection

## Start

After completing this assignment, I want to start defining my classes and planning the structure of my program before I begin coding. One of the hardest parts of this 
assignment was building the engine classes, and I realized that having a clearer idea of what each class is responsible for makes the implementation easier. 
In future projects, I want to spend more time thinking about the structure of the program and how the different classes will work together before jumping into the code.

## Stop

I want to stop jumping directly into implementation without fully understanding what each class or method should be responsible for. I sometimes prefer 
figuring things out while I am coding, but this assignment showed me that this can make things more difficult later. Planning the responsibilities of each class first 
can make the code easier to understand, test, and maintain.

## Continue

I want to continue using the Arrange-Act-Assert (AAA) structure when writing unit tests. It helped me keep my tests organized and made it easy to understand what each 
test was doing. I also want to continue using TDD when it is appropriate and testing smaller parts of a program individually instead of waiting until the entire program 
is finished.

## Self improvement
One of the areas where I improved the most during this assignment was unit testing and using those tests to guide the implementation of my classes. I had previously used 
unit testing and TDD in projects during my second semester, but this assignment gave me more experience with the process. For example, a failing rounding test helped 
identify a problem with the rounding and penny reconciliation logic. Having a test with a specific expected result made it easier to identify where the implementation 
was behaving incorrectly.

## Overall
I found TDD very useful, even though it was a little annoying at first because it is not normally the way I approach programming. As I continued working on 
the assignment, I became more comfortable building the tests first and then writing the code needed to make them pass. This assignment helped me better understand how 
unit tests can do more than check finished code; they can also help guide how the code is designed and implemented.
